实际工作时

不用打开五个面板，看一眼就够。

开始长任务或切换工具前，打开 BirdNion。它根据各个已启用数据源的真实反馈，回答三个问题；连接异常时也会明确提示，不会凭空编出数字。

  1. 01

    还剩多少额度？

    每张卡片都会显示服务商提供的额度周期：5 小时、每周、每月、点数或预算。服务商未提供的周期会标为不可用。

  2. 02

    什么时候能再用？

    重置倒计时帮你判断该等一等、换个工具，还是继续。Quota Agenda 按先后列出各服务商接下来的重置时间，只采用服务商明确提供的时间。

  3. 03

    这个数据源需要处理吗？

    登录过期或密钥失效时，卡片会明确提示。直接跳到对应服务商的设置，修复数据源，再重新执行实际检查。

macOS 和 Linux 还支持统计 17 种智能体来源的每日本地费用，数据来自 Claude、Codex、Grok、Kiro、Oh My Pi、Pi、Devin、OpenCode、Gemini CLI、Copilot CLI、Antigravity、Cursor、Amp、Droid、Kimi、Qwen Code 和 Goose 的会话日志。

不打扰你的工作

不用离开编辑器，抬眼就能看。

在 macOS 上，BirdNion 常驻菜单栏；开启菜单栏百分比后，即可在图标旁看到剩余额度。在 Linux 上，托盘图标直接显示百分比和服务商标识，默认开启。两个平台都会轮流展示你的服务商，优先显示已有额度消耗的服务商。

读取哪些数据

无需 BirdNion 后端
或账号。

BirdNion 读取你启用的服务商所公开说明的数据源，并在固定安装路径中查找编程智能体，读取其本地会话日志以统计费用历史。不会扫描整个磁盘。你可以在设置中更改每个服务商的数据源；启用的数据源仍会连接对应的服务商。

密码
BirdNion 从不存储密码。
已有登录状态
支持时直接复用。OAuth、Keychain 和 CLI 会话仍由原工具管理。
你输入的密钥
以明文保存在 BirdNion 的本地文件中，仅你的用户账号可读取。
浏览器 Cookie
默认使用“自动”模式，支持 Cookie 的服务商只会从浏览器读取自己站点的 Cookie。你可为每个服务商单独切换为“手动”或“关闭”。
项目洞察
仅保存文件夹名称和哈希 ID，不保存完整路径。

请这只小鸟进门前，你可能想问

BirdNion 会扫描我的整台电脑吗？

不会。它只检查一组固定安装路径来查找编程智能体，读取这些智能体的本地会话日志以统计费用历史，并读取你启用的服务商所公开说明的数据源。不会递归扫描文件系统。

需要重新登录吗？

取决于服务商。BirdNion 可以复用受支持的 CLI、OAuth 或浏览器会话；其他数据源则需要你明确提供密钥或配置。

所有服务商都提供相同的数据吗？

不是。每张卡片只反映该服务商或本地数据源实际提供的内容，数据不可用时也会如实显示。

Linux 版与 macOS 版有什么不同？

Linux 托盘图标默认显示百分比，macOS 菜单栏百分比则需手动开启。Linux 版不支持全局快捷键，面板无悬停提示，仅提供 x86_64 安装包，也不显示 Codex 代码审查用量。

BirdNion 收费吗？

不收费。BirdNion 采用 MIT 许可，无需 BirdNion 账号。你所用服务商的套餐和 API 计费仍照常适用。

macOS 首次启动时会弹出警告吗？

只会在首次启动时显示常规的“从互联网下载”确认提示。应用已使用 Developer ID 签名并通过 Apple 公证，因此可通过 Gatekeeper 检查。
