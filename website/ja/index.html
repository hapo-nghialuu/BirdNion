コーディングは、そのまま。
利用上限は BirdNion が見守ります。

Claude、Codex、Gemini など、ツールごとに利用状況の確認場所はばらばら。BirdNion なら、選んだプロバイダーへの接続だけを使って、残りの利用枠とリセット時期をワンクリックで確認できます。

実際の作業中に

5 つのダッシュボードより、ひと目で。

長い作業の前やツールを切り替えるときに、BirdNion を開いてみてください。有効にした各データ取得元から実際に得た情報で、3 つの疑問に答えます。接続に問題があれば、数字でごまかさずにお知らせします。

  1. 01

    あとどれくらい使える？

    各カードには、プロバイダーが提供する 5 時間・週間・月間の利用枠や、クレジット・予算を表示します。プロバイダーが情報を提供していない枠は、取得不可のまま表示します。

  2. 02

    いつまた使える？

    リセットまでのカウントダウンで、待つか、ツールを切り替えるか、そのまま続けるかを判断できます。Quota Agenda は、プロバイダーが実際に報告する時刻だけを使い、次のリセットをプロバイダー横断で順番に並べます。

  3. 03

    このデータ取得元に問題はある？

    ログインの有効期限が切れたり、キーが使えなくなったりすると、カードでお知らせします。該当するプロバイダーの設定へ直接移動し、取得元の問題を修正して、実際の接続確認をやり直せます。

macOS と Linux の両方で、17 種類のエージェントのセッションログから日別ローカルコストも確認できます — Claude、Codex、Grok、Kiro、Oh My Pi、Pi、Devin、OpenCode、Gemini CLI、Copilot CLI、Antigravity、Cursor、Amp、Droid、Kimi、Qwen Code、Goose に対応。

  1. 01BirdNion をインストール

    macOS では Homebrew、Linux ではリリースパッケージを使います。

  2. 02プロバイダーを 1 つ選ぶ

    Claude、Codex、Grok には、初めての接続を案内するガイドがあります。

  3. 03接続を確認する

    BirdNion は選んだ設定を保存し、実際のデータ取得元を確認してから「接続中」と表示します。

    デモではなく、実際の利用枠とリセット情報のカードで、接続できたことを確認できます。

読み取るデータ

BirdNion のバックエンドも
アカウントも不要。

BirdNion は、有効にしたプロバイダーの文書化されたデータ取得元を読み取ります。また、決まったインストール先で見つかったコーディングエージェントのローカルセッションログを、コスト履歴のために読み取ります。ディスク全体のスキャンはしません。取得元はプロバイダーごとに設定で変更でき、有効な取得元はそれぞれのプロバイダーと通信します。

パスワード
BirdNion が保存することはありません。
既存のログイン
対応している場合は再利用します。OAuth、Keychain、CLI のセッションは、元のツールがそのまま管理します。
入力したキー
BirdNion のローカルファイルに平文で保存します。読み取りは、お使いのユーザーアカウントだけに許可されます。
ブラウザーのクッキー
標準の「自動」では、クッキー対応のプロバイダーが、ブラウザーから自分のサイトのクッキーだけを読み取ります。プロバイダーごとに「手動」や「オフ」に変更できます。
プロジェクト分析
フォルダー名とハッシュ化した ID のみを保存し、フルパスは保存しません。

この小鳥を迎える前に、よくある質問

BirdNion はパソコン全体をスキャンしますか？

いいえ。決まったインストール先の一覧からコーディングエージェントを探し、そのローカルセッションログをコスト履歴のために読み取ります。また、有効にしたプロバイダーの文書化されたデータ取得元を読み取ります。ファイルシステムを再帰的にスキャンすることはありません。

もう一度ログインする必要はありますか？

プロバイダーによります。対応する CLI、OAuth、ブラウザーのセッションは再利用できます。それ以外の取得元には、キーの入力や設定が必要です。

どのプロバイダーでも同じデータを見られますか？

いいえ。各カードは、取得不可の状態も含めて、プロバイダーやローカルの取得元が実際に提供する情報だけを表示します。

Linux 版と macOS 版は何が違いますか？

Linux 版はトレイアイコンにパーセントを標準で表示しますが、macOS 版のメニューバーでは設定で有効にする必要があります。Linux 版はグローバルホットキーとパネルのホバーツールチップに非対応で、x86_64 パッケージのみを提供し、Codex のコードレビュー利用量は表示しません。

BirdNion は有料ですか？

いいえ。BirdNion は MIT ライセンスで公開されており、BirdNion のアカウントも不要です。各プロバイダーのプランや API の料金は、通常どおり適用されます。

macOS で初回起動時に警告は出ますか？

初回起動時に、通常の「インターネットからダウンロードされた」アプリの確認だけが表示されます。Developer ID で署名し、Apple の公証を取得しているため、Gatekeeper で許可されます。
