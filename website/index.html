DURING A REAL WORK SESSION

One glance instead of five dashboards.

Before a long task or a tool switch, open BirdNion. It answers three questions from what each enabled source actually reports—and says when a connection needs attention instead of inventing a number.

  1. 01

    How much is left?

    Each card shows the quota windows its provider exposes—5-hour, weekly, monthly, credits or budget. A window the provider does not report stays marked unavailable.

  2. 02

    When can I use it again?

    Reset countdowns tell you whether to wait, switch tools or keep going. Quota Agenda lines up the next resets across providers, using only reset times the providers report.

  3. 03

    Does this source need attention?

    When a sign-in expires or a key stops working, the card says so. Jump to the exact provider setting, fix the source and run the real check again.

Also on macOS and Linux: daily local cost from Claude, Codex, Grok, Kiro, Oh My Pi and Pi session logs. macOS also reads Devin.

STAYS OUT OF YOUR WAY

Glance up without leaving your editor.

WHAT IT READS

No BirdNion backend
or account.

BirdNion reads the documented sources of the providers you enable, plus the local session logs of coding agents it finds at fixed install paths, for cost history. No full-disk scan. You can change each provider's source in Settings, and an enabled source still talks to its own provider.

Passwords
Never stored by BirdNion.
Existing sign-ins
Reused where supported. OAuth, Keychain and CLI sessions stay with the tools that own them.
Keys you enter
Saved as plain text in BirdNion's local files, readable only by your user account.
Browser cookies
On Auto, the default, a provider that supports cookies reads only its own site's cookies from your browser. Switch it to Manual or Off per provider.
Project insights
Saved as a folder name and a hashed ID, never the full path.

Questions before you invite this bird in

Will BirdNion scan my whole computer?

No. It checks a fixed list of install paths to find coding agents, reads those agents' local session logs for cost history, and reads the documented sources of the providers you enable. There is no recursive filesystem scan.

Do I need to sign in again?

It depends on the provider. BirdNion can reuse supported CLI, OAuth or browser sessions; other sources require an explicit key or configuration.

Does every provider expose the same data?

No. Each card reflects only what that provider or local source actually exposes, including unavailable states.

How is Linux different from macOS?

The Linux tray icon shows the percent by default, while macOS menu-bar percentages are opt-in. Linux has no global hotkey and no hover tooltip on the panel, ships x86_64 bundles only, and does not show Codex code-review usage.

Does BirdNion cost anything?

No. BirdNion is MIT licensed and needs no BirdNion account. Your providers' own plans and API pricing still apply.

Will macOS warn me on first launch?

The current app is ad-hoc signed. Homebrew removes quarantine during install; if macOS still blocks it, use Right-click → Open.
