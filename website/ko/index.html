실제 작업 중에

대시보드 다섯 개 대신 한눈에.

긴 작업을 시작하거나 도구를 바꾸기 전에 BirdNion을 열어 보세요. 활성화한 각 소스가 실제로 제공하는 데이터로 세 가지 질문에 답합니다. 연결에 문제가 있으면 임의의 숫자 대신 점검이 필요하다고 알려 줍니다.

  1. 01

    얼마나 남았나요?

    각 카드는 제공업체가 공개하는 5시간·주간·월간 한도, 크레딧 또는 예산을 보여 줍니다. 제공업체가 보고하지 않는 항목은 확인 불가로 표시합니다.

  2. 02

    언제 다시 쓸 수 있나요?

    초기화까지 남은 시간을 보고 기다릴지, 도구를 바꿀지, 계속할지 결정하세요. Quota Agenda는 제공업체가 보고한 초기화 시점만으로 여러 제공업체의 다음 초기화 일정을 정리해 줍니다.

  3. 03

    이 소스를 점검해야 하나요?

    로그인이 만료되거나 키가 작동하지 않으면 카드에 알려 줍니다. 해당 제공업체의 설정으로 바로 이동해 소스를 수정하고 실제 연결을 다시 확인하세요.

macOS와 Linux 모두에서 17개 에이전트 소스의 일별 로컬 비용도 확인할 수 있습니다. Claude, Codex, Grok, Kiro, Oh My Pi, Pi, Devin, OpenCode, Gemini CLI, Copilot CLI, Antigravity, Cursor, Amp, Droid, Kimi, Qwen Code, Goose의 세션 로그를 사용합니다.

작업을 방해하지 않아요

에디터를 떠나지 않고 한눈에 확인하세요.

macOS에서는 BirdNion이 메뉴 막대에 표시됩니다. 메뉴 막대 백분율 표시를 켜면 아이콘 옆에서 남은 한도를 볼 수 있습니다. Linux에서는 기본적으로 트레이 아이콘 자체에 백분율과 제공업체 로고가 표시됩니다. 두 플랫폼 모두 제공업체를 순환 표시하며, 한도를 사용 중인 제공업체를 먼저 보여 줍니다.

  • Linux x86_64DEB · RPM · AppImage

현재 제한 사항

  • macOSDeveloper ID 서명 및 공증 완료
  • Linuxx86_64 번들만 제공
  • Linux전역 단축키 및 패널의 마우스 오버 툴팁 미지원

읽는 데이터

BirdNion 백엔드도,
계정도 필요 없어요.

BirdNion은 활성화한 제공업체의 문서에 명시된 소스와, 정해진 설치 경로에서 찾은 코딩 에이전트의 로컬 세션 로그를 읽어 비용 내역을 만듭니다. 전체 디스크를 스캔하지 않습니다. 설정에서 제공업체별 소스를 바꿀 수 있으며, 활성화된 소스는 해당 제공업체와 직접 통신합니다.

비밀번호
BirdNion은 저장하지 않습니다.
기존 로그인
지원되는 경우 재사용합니다. OAuth, Keychain, CLI 세션은 원래 도구가 계속 관리합니다.
직접 입력한 키
본인 사용자 계정만 읽을 수 있는 BirdNion 로컬 파일에 일반 텍스트로 저장합니다.
브라우저 쿠키
기본값인 자동 모드에서는 쿠키를 지원하는 제공업체가 브라우저에서 자기 사이트의 쿠키만 읽습니다. 제공업체별로 수동 또는 끄기로 바꿀 수 있습니다.
프로젝트 인사이트
전체 경로 대신 폴더 이름과 해시 처리한 ID만 저장합니다.

이 작은 새를 맞이하기 전 궁금한 점

BirdNion이 컴퓨터 전체를 스캔하나요?

아니요. 정해진 설치 경로 목록에서 코딩 에이전트를 찾고, 비용 내역을 위해 해당 에이전트의 로컬 세션 로그와 활성화한 제공업체의 문서에 명시된 소스를 읽습니다. 파일 시스템을 재귀적으로 스캔하지 않습니다.

다시 로그인해야 하나요?

제공업체에 따라 다릅니다. BirdNion은 지원되는 CLI, OAuth, 브라우저 세션을 재사용할 수 있습니다. 그 밖의 소스는 키를 직접 입력하거나 설정해야 합니다.

모든 제공업체가 같은 데이터를 제공하나요?

아니요. 각 카드는 해당 제공업체나 로컬 소스가 실제로 제공하는 데이터만 보여 주며, 확인할 수 없는 항목은 그대로 표시합니다.

Linux는 macOS와 어떻게 다른가요?

Linux 트레이 아이콘은 기본적으로 백분율을 표시하지만, macOS 메뉴 막대의 백분율 표시는 직접 켜야 합니다. Linux는 전역 단축키와 패널의 마우스 오버 툴팁을 지원하지 않으며, x86_64 번들만 제공하고 Codex 코드 리뷰 사용량은 표시하지 않습니다.

BirdNion은 유료인가요?

아니요. BirdNion은 MIT 라이선스로 제공되며 BirdNion 계정도 필요 없습니다. 각 제공업체의 요금제와 API 요금은 그대로 적용됩니다.

macOS에서 처음 실행할 때 경고가 뜨나요?

처음 실행할 때 일반적인 “인터넷에서 다운로드한 앱” 확인만 표시됩니다. 앱은 Developer ID로 서명하고 Apple 공증을 받아 Gatekeeper 검증을 통과합니다.
